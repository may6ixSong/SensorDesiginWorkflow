# Calypso Web — 당분간 쓰지 않습니다 (deprecated)

> **이 앱은 지금 운영하지 않습니다.** 코드는 그대로 두되, 서비스로 띄우거나
> 여기로 사용자를 보내지 않습니다. 설계서 §11.5 참고.

## 왜 멈춰 뒀나

Calypso를 별도 웹앱으로 띄우면 아키텍처 그림은 깨끗한데, 사용자 입장에선
"산출물 올리러 딴 서비스로 가라"는 이동 비용만 남습니다. project 메타 정보·SSO
인증·권한이 전부 SIREN과 동일하기 때문에, 앱을 갈라서 얻는 실익이 지금은 없습니다.

그래서 **산출물 등록·관리 화면은 SIREN web 안에 두고, 그 화면이 Calypso api를
직접 호출**하는 방식으로 갑니다. 바뀐 것은 인터페이스의 위치뿐이고, 데이터
소유권은 그대로입니다 — 산출물의 실물과 버전 이력은 여전히 **Calypso 백엔드가
소유**합니다(`calypso/`는 계속 분리 운영).

## 언제 다시 켜나

아래 두 가지가 같이 성립할 때입니다.

1. 산출물이 실제로 많이 쌓여 Calypso 자체 화면(검색·필터·대량 관리)이 필요해질 때
2. 산출물이 "파일 업로드"가 아니라 **template 기반의 구조화된 데이터 저장**으로
   바뀔 때 — 그러면 Calypso가 자기만의 편집 UI를 갖게 되므로 SIREN 안에 복제할
   이유가 사라집니다

전환 비용은 낮습니다. 백엔드가 이미 분리돼 있어 데이터 이관이 없고, SIREN에서
걷어낼 것은 화면 코드와 진입점 링크뿐입니다.

## 지우지 않는 이유

설계 결정이 최종 확정된 게 아니라 **시점을 미룬 것**이기 때문입니다. 여기 있는
AppShell·Project List·산출물 목록/등록 화면은 위 2번 시점에 그대로 되살려 쓸
자산입니다.

## 그래도 띄워 보려면

```bash
npm install
npm run dev          # http://localhost:5174
```

`.env.development`에 `SIREN_API`(project 목록 조회)와 `CALYPSO_API`가 필요하고,
SIREN api의 `CORS_ORIGIN`에 `http://localhost:5174`가 들어 있어야 합니다.
